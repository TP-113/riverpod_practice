# 実際に機能を開発してみよう！

このレッスンでは、これまでに学んだことを生かしつつ実際に機能を開発してみましょう。

## extra 課題 １

「ユーザー情報管理」ページで登録したユーザー情報について、アプリを再起動しても情報が保持されたままになるようにしましょう。ユーザー情報をローカルストレージに保存することでこれを実現しましょう。

**ヒント**

- ローカルストレージへの保存は[shared_preferences](https://pub.dev/packages/shared_preferences)を利用しましょう

## extra 課題 2

タイマーアプリにラップタイム機能を追加しましょう。

### ラップタイム機能の説明

- 「ラップ」ボタンが画面に配置されている
- ラップボタンを押すと、その時点での経過時間が保存される
- 保存された経過時間は、画面の下部に表示される
- ラップボタンを押すごとに画面の下部にラップ時間の UI が追加されていく
- リセットボタンを押すと、これまで保存したラップ時間が全て削除される

**ヒント**

- ラップ情報を表現するための Freezed クラスを定義しましょう
- ラップ情報を保持し、更新するための Provider を定義しましょう
- ラップ情報の UI が画面下に追加されていくと、画面から溢れてしまいます。スクロールで全てを閲覧できるように、ListView を使いましょう
